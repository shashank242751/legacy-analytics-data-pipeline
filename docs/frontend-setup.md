# Phase 1: Frontend & Google Analytics 4 (GA4) Setup Guide

This document explains step-by-step how the website was created, how the GA4 Property and Web Data Stream were created, and how events were tracked.

---

## 1. Creating the GA4 Property in Google Analytics

1. Navigate to [Google Analytics](https://analytics.google.com/) and sign in.
2. In the bottom-left corner, click **Admin (⚙️)**.
3. Click **Create** &gt; **Property**:
   - **Property Name**: `POC-Analytics-BigQuery`
   - **Reporting Timezone**: `India Standard Time (GMT+05:30)`
   - **Currency**: `Indian Rupee (₹)`
4. Under **Business Objectives**, select **Get baseline reports** (or *Examine user behaviour*).
5. Click **Create** and accept the Google Terms of Service.
6. Note down the **Property ID** generated by Google (e.g. `561103303`, found under **Admin** &gt; **Property Details**).

---

## 2. Setting Up the Web Data Stream

1. Under the newly created property, go to **Data Collection** &gt; click **Web**.
2. **Website URL**: Enter `localhost.test` (or `example.com`).
   - *Important Note*: Google Analytics requires a valid domain format with a dot (`.`). It does **not** allow port numbers (like `:5500`) or paths (like `/index.html`) in this setup box.
   - This URL is purely an administrative identifier. It does **not** block or restrict events sent from your local development server (`http://127.0.0.1:5500` or `http://localhost`).
3. **Stream Name**: `POC Test Site`
4. Keep **Enhanced Measurement** enabled (blue toggle).
5. Click **Create and Continue**.
6. Google will generate your unique **Measurement ID**:
   ```
   G-N7653XPQQZ
   ```

---

## 3. Integrating the Google Tag into Frontend Code

In your website (`frontend/index.html`), place the official `gtag.js` script right after the `<head>` tag:

```html
<!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-N7653XPQQZ"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());

  // debug_mode: true enables real-time inspection in GA4 DebugView
  gtag('config', 'G-N7653XPQQZ', {
    debug_mode: true
  });
</script>
```

---

## 4. Triggering User Events from JavaScript

In `frontend/app.js`, user actions are captured and dispatched to GA4:

### 1. Page Views (Virtual Navigation)
```javascript
gtag('event', 'page_view', {
  page_title: 'Page - HOME',
  page_path: '/home',
});
```

### 2. Custom Button Clicks
```javascript
gtag('event', 'button_click', {
  button_label: 'Sign Up',
  action_type: 'signup_click',
});
```

### 3. Custom Business Events with Values
```javascript
gtag('event', 'poc_action', {
  action_name: 'mock_checkout',
  value: 49.99,
  currency: 'USD',
});
```

---

## 5. Verifying Data Collection in GA4

1. Open `frontend/index.html` via VS Code Live Server (`http://127.0.0.1:5500/frontend/index.html`).
2. Click the navigation links and buttons several times.
3. In Google Analytics:
   - Go to **Reports** &gt; **Realtime**: Verify that **Active Users in last 30 minutes** shows `1` and event counts are incrementing.
   - Go to **Admin** &gt; **Data display** &gt; **DebugView**: Inspect the timeline of individual event payloads and parameters in real time.
